# stattotex
A Stata command to automatically place a calculation into LaTeX -- no more hard coding!

See the PDF and do file for more details and some examples.

To download, run the following command:  `ssc install stattotex`, or alternatively run `net install stattotex, from("https://raw.github.com/isapollnik/stattotex/master/src/") replace`

If you have comments or suggestions, please feel free to contact me.
